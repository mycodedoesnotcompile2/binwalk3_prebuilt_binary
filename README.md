Binwalk version 3 prebuilt binaries
====================================

Description
-----------
The great ["binwalk"](https://github.com/ReFirmLabs/binwalk) tool, from ReFirmLabs, automatically compiled when there is a new release.

The building workflow is [here](https://github.com/mycodedoesnotcompile2/binwalk3_prebuilt_binary/blob/main/.github/workflows/build.yml).

See the [Github release page](https://github.com/mycodedoesnotcompile2/binwalk3_prebuilt_binary/releases/latest) of this repository to access prebuilt binaries for for different:
* OSes: Linux, Windows, MacOS
* architectures: x64, arm64, powerpc64, riscv64, mips64, loongarch64
* libc: GNU, musl

For each release here, the tag corresponds to the latest short commit ID `git rev-parse --short HEAD` of the current latest main branch of [binwalk Github repository](https://github.com/ReFirmLabs/binwalk).
